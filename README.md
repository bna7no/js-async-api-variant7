# Практична робота 10.2 — Async/Await та API

## Варіант 7 — Country Explorer

## Опис

Додаток для перегляду інформації про країни світу з використанням REST Countries API.

---

## Реалізований функціонал

### Список країн
Завантаження всіх країн через Fetch API.

### Пошук країн
Пошук за назвою країни.

### Фільтрація
Фільтрація за регіоном:
- Europe
- Asia
- Africa
- Americas
- Oceania

### Детальна інформація
Для кожної країни відображаються:
- прапор
- назва
- столиця
- регіон
- населення
- мови
- валюта

### Async/Await
Усі HTTP-запити реалізовані через async/await.

### Error Handling
Обробка помилок через try/catch.

### Loading State
Показ повідомлення "Завантаження..." під час запиту.

---

## REST Countries API

```text
https://restcountries.com/v3.1/all
```

---

## Інструкція запуску

1. Відкрити проєкт у VS Code
2. Запустити index.html через Live Server
3. Натиснути кнопку "Завантажити країни"
4. Використовувати пошук та фільтрацію
